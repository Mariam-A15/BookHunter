# BookHunter
A data scraping and database design project named BookHunter, built using Python, BeautifulSoup, and SQLite. It extracts all books with their details from Books to Scrape website and organizes them into relational tables.
# BookHunter
A Python project for scraping all books from [Books to Scrape](https://books.toscrape.com/) and storing them in an SQLite database using BeautifulSoup and sqlite3.

# Features
- Extracts all categories and books automatically
- Stores data in normalized tables (Categories & Books)
- Built using Jupyter Notebook and DB Browser for SQLite

# Tech Stack
- Python (requests, BeautifulSoup4)
- SQLite
- DB Browser for SQLite

# Project Files
- `NoteBook.ipynb` 
- `Srap_Library.py'
